Dados do catálogo

  • Lista de jogos licenciados — Wikipedia, List of Sega Genesis games. Fonte dos 880 títulos (desenvolvedora, publicadora, datas de lançamento por região).

Capas dos jogos

  • libretro-thumbnails — github.com/libretro-thumbnails/Sega_-_Mega_Drive_-_Genesis. Repositório de capas usado em data/boxarts.json, com precedência para a versão Tec Toy/Brasil, depois USA/Europe/World e por último Japão.
  • jsdelivr — jsdelivr.com. CDN usada como fonte primária para carregar as imagens de capa sob demanda.
  • thumbnails.libretro.com — thumbnails.libretro.com. Host oficial do libretro-thumbnails, usado como fallback caso o jsdelivr falhe.
